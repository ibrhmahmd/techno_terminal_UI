API Reference & Documentation

Base URL

http://<server>:8000/api/v1

Authentication

All API requests require authentication using JWT (JSON Web Token):

Authorization: Bearer <JWT>

Core Endpoints

/students

Student Directory & Management

/groups

Group / Class Management

/enrollments

Enrollment Operations

/attendance

Attendance Tracking

/finance

Financial Transactions & Receipts

/staff

Staff Management & HR

/reports

Analytics & Reporting

Role-Based Access

Different user roles have different levels of access:

  • Admin: Full access to all modules
  • Manager: Full access to operations
  • Instructor: Read-only Dashboard and Directory
  • Receptionist: Access to Directory, Enrollments, and Finance

Response Format

All responses are returned in JSON format with standardized structure: 

{
  "status": "success" | "error",
  "data": { /* response data */ },
  "message": "Human-readable message"
}
