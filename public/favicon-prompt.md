# Favicon Design Prompt

## For Image Generation Models (DALL-E, Midjourney, etc.)

```
Design a minimal, modern app favicon icon for "TechnoTerminal" — a CRM dashboard for a tech education company.

Concept: Combine the letter "T" with a terminal/shell prompt symbol (>).

Layout:
- Square icon with rounded corners (10px radius)
- Dark navy background (#131b2e)
- Left side: Clean, geometric "T" letterform in teal (#006a61)
- Right side: Terminal prompt chevron ">" symbol in light teal (#86f2e4)

Style:
- Flat design, no gradients, no shadows
- Minimal, geometric, vector-clean
- Works at 16x16px (favicon) and 48x48px
- No text, no busy details
- Similar aesthetic to modern SaaS logos (Linear, Vercel, Supabase)

Color palette:
- Background: #131b2e (dark navy)
- Primary: #006a61 (teal)
- Accent: #86f2e4 (light teal)

Do NOT include:
- Gradients or 3D effects
- Multiple colors beyond the 3 specified
- Complex details that won't scale
- Text or letters other than "T"
```

## Output Requirements
- Format: SVG (preferred) or PNG at 48x48px minimum
- Transparent background optional (but dark navy preferred)
- Must be recognizable at 16x16px favicon size
