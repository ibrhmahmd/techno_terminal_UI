# TechnoTerminal CRM - Project Brief

## Overview
**Project Name**: TechnoTerminal CRM  
**Type**: Robotics Center Management Platform  
**Version**: 1.1  
**Status**: Phase 2 - Backend Integration (Active Development)  
**MVP Completion Date**: April 2, 2026  
**Last Updated**: April 12, 2026  

## Core Purpose
A comprehensive CRM system designed specifically for robotics education centers to manage students, classes, staff, finances, and competitions in a high-density, professional interface.

## Key Goals
1. **Streamline Operations**: Centralize all robotics center management tasks
2. **Enhance Visibility**: Real-time dashboards for attendance, enrollments, and finances
3. **Improve Efficiency**: Reduce administrative overhead with intuitive workflows
4. **Professional Experience**: Create a sophisticated, lab-like interface that matches the robotics environment

## Target Users
- **Primary**: Robotics center administrators and managers
- **Secondary**: Teaching staff, finance personnel, enrollment coordinators

## Core Modules (MVP)
1. **Dashboard** - Real-time operations overview
2. **Groups** - Class and session management
3. **Directory** - Student and parent lookup
4. **Enrollments** - Student-to-group mapping
5. **Finance** - Payment and receipt management
6. **Reports** - Analytics and insights

## Extended Modules
7. **Staff** - Personnel management
8. **Attendance** - Detailed tracking
9. **Competitions** - Event management
10. **Students** - Individual profiles
