# Quickstart: Dashboard Audit Fix

## Setup

```bash
# Ensure you're on the correct branch
git checkout 041-fix-dashboard-audit

# Install dependencies (if not already done)
npm install
```

## Running the Build

```bash
npm run build    # tsc -b && vite build — must pass with zero errors
npm run lint     # ESLint — must pass with zero errors
```

## Testing

```bash
npm run test                         # All tests
npm run test -- src/tests/Dashboard.test.tsx   # Dashboard-specific (if exists)
```

## Verification Checklist

After implementing: run `npm run build && npm run lint`. If both pass:

1. Open the app in browser, navigate to `/dashboard`
2. Verify session times show in 12h format (e.g., "9:00 AM" not "09:00")
3. Tab through the page — hidden FAB buttons should not receive focus
4. Open the mobile FAB, press Escape — should close
5. Tab into day selector — use ArrowLeft/ArrowRight to navigate tabs
6. Check error banner has `role="alert"` in DOM inspector
